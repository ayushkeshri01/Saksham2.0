# Routes Config

Mapping of page routes in the Next.js App Router project:

## / (National Overview Dashboard)
* URL Path: `/`
* Component File: `src/app/page.tsx`
* Layout: `src/app/layout.tsx`
* Summary: The main landing view showing the national overview, KPI metrics, choropleth map visualization, and top active states.

## /model-analysis (Model-wise Analysis)
* URL Path: `/model-analysis`
* Component File: `src/app/model-analysis/page.tsx`
* Layout: `src/app/layout.tsx`
* Summary: Detailed model-wise replacement counts, vehicle ages, failure causes, and sparkline trends.
